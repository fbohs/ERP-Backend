# File Index

> Full file-level reference for the `src/` tree. Use this when you know the concept but not the file. For the high-level picture, see [`docs/architecture.md`](./architecture.md).

## Entry Points

| File | Role |
|---|---|
| `src/main.ts` | Process entry — `validateConfig → assertInfraReady → buildApp → listen` |
| `src/app.ts` | `buildApp(overrides?)` — wires all plugins, starts workers, registers `onClose` for graceful shutdown |

## Types

| File | Role |
|---|---|
| `src/types/db.ts` | Kysely `DB` interface — generated by `kysely-codegen` from the live database. Never edit by hand; run `npm run db:codegen` after migrations |
| `src/types/fastify.d.ts` | Fastify type augmentations — extends `FastifyRequest` with `request.user: CachedSession` |

## `src/shared/`

### config

| File | Role |
|---|---|
| `src/shared/config/index.ts` | Typed `config` object (reads `process.env` once at module load) and `validateConfig()` (called at startup) |

### db

| File | Role |
|---|---|
| `src/shared/db/index.ts` | `createDb(url)` — Kysely instance factory with Postgres dialect. `AppDb` type exported for use in repositories |

### cache

| File | Role |
|---|---|
| `src/shared/cache/redis.ts` | `createRedis(url)` — ioredis client factory. Called twice in `buildApp`: once for session Redis, once for queue Redis |

### auth

| File | Role |
|---|---|
| `src/shared/auth/authenticate.ts` | Tenant auth hook — Redis fast path → Postgres slow path. Populates `request.user` |
| `src/shared/auth/authenticate-platform.ts` | Platform auth hook — DB-only lookup by SHA-256 token hash. No Redis cache |
| `src/shared/auth/authorize.ts` | Role-based access control hook — checks `request.user.role` against required roles |
| `src/shared/auth/ip-allowlist.ts` | `createIpAllowlist(csv)` — parses `PLATFORM_IP_ALLOWLIST`, exposes `.allows(ip)` |
| `src/shared/auth/permissions.ts` | Permission constants and role-to-permission map |
| `src/shared/auth/session.ts` | `sessionCacheKey(token)` — Redis key builder; `CachedSession` type |
| `src/shared/auth/platform-session.ts` | Platform session helpers — token generation, hash, TTL constants |
| `src/shared/auth/token-hash.ts` | SHA-256 hashing for stored tokens (platform sessions, login tokens) |
| `src/shared/auth/index.ts` | Public re-exports |

### audit

| File | Role |
|---|---|
| `src/shared/audit/audit.repository.ts` | `AuditRepository` — writes to tenant `AuditLog`. Always called inside the same transaction as the operation |
| `src/shared/audit/platform-audit.repository.ts` | `PlatformAuditRepository` — writes to `PlatformAuditLog`. Used by platform module and CLI scripts |
| `src/shared/audit/index.ts` | Public re-exports |

### errors

| File | Role |
|---|---|
| `src/shared/errors/base.ts` | Error base classes — `AppError`, `NotFoundError`, `UnauthorizedError`, `ForbiddenError`, `ConflictError`, `ValidationError` |
| `src/shared/errors/handler.ts` | Fastify `setErrorHandler` — maps `AppError` subclasses to HTTP status codes, formats error response |

### idempotency

| File | Role |
|---|---|
| `src/shared/idempotency/idempotency.ts` | `IdempotencyStore` — get/set idempotency keys in queue Redis. Used by mutation routes that accept `Idempotency-Key` header |
| `src/shared/idempotency/index.ts` | Public re-exports |

### infra

| File | Role |

### logging

### queue

### email

### storage

## `src/scripts/`

CLI scripts that run outside the HTTP server. Each has a `.ts` (logic) and a `.cli.ts` (thin entry point that calls the logic and exits). They connect directly to Postgres and Redis via env vars.

| File | Role |
|---|---|
| `src/scripts/create-platform-admin.ts` | Create a new `PlatformAdmin` row |
| `src/scripts/create-platform-admin.cli.ts` | CLI entry point for the above |
| `src/scripts/update-platform-admin.ts` | Update name / email / active status of a `PlatformAdmin` |
| `src/scripts/update-platform-admin.cli.ts` | CLI entry point |
| `src/scripts/revoke-platform-admin-sessions.ts` | Delete all active sessions for a `PlatformAdmin` |
| `src/scripts/revoke-platform-admin-sessions.cli.ts` | CLI entry point |
| `src/scripts/verify-s3.ts` | Smoke-test S3 connectivity (upload + delete a test object) |
| `src/scripts/__tests__/` | Tests for each script (Testcontainers) |
